# Steps 1–7 구현 정리

## Step 1 — 마포구 카페 상권 통계 (2024년 포함)

### 뭘 했나

서울 열린데이터광장 API에서 마포구 카페 데이터를 수집해 RAG에 저장

- 추정매출 (상권별 월 매출금액, 요일별·시간대별 매출)
- 점포현황 (점포수, 개업률, 폐업률, 생존율)
- 2021Q4 ~ 2024Q4 전 분기, 총 927개 청크

### 어떻게 좋나

AI가 "홍대입구 카페 평균 월매출이 얼마" 같은 실제 수치를 근거로 분석 가능

### 프론트에서 어떻게 보이나

AI 분석 시작 → Claude 답변에 이런 내용이 나옴:

```
홍대입구 상권 카페 평균 월 매출건수는 45,000건으로,
금요일·토요일 매출이 전체의 40%를 차지합니다.
```

## Step 2 — 상권변화지표 (HH/HL/LH/LL)

### 뭘 했나

서울시 CSV 파일을 파싱해서 상권 등급 데이터를 저장

| 코드 | 의미                                  |
| ---- | ------------------------------------- |
| HH   | 매출·유동인구 모두 높음 (핵심 상권)   |
| HL   | 매출 높고 유동인구 낮음 (목적형 상권) |
| LH   | 유동인구 많은데 매출 낮음 (경쟁 과열) |
| LL   | 둘 다 낮음 (침체 상권)                |

### 어떻게 좋나

"내 카페가 있는 상권이 지금 성장 중인지 침체 중인지" 맥락 제공

### 프론트에서 어떻게 보이나

AI 답변에 이런 내용이 나옴:

```
현재 합정역 상권은 LH 등급(유동인구 많고 매출 낮음)으로
경쟁이 과열된 상태입니다. 차별화 전략이 필요합니다.
```

## Step 3 — 마포구 유동인구 (5,824청크)

### 뭘 했나

행정동별 시간대·요일·연령대별 유동인구를 2021Q4~2024Q4 전 분기 수집

### 어떻게 좋나

"금요일 저녁 유동인구가 몇 명인지"를 AI가 알고 매출 패턴과 연결 가능

### 프론트에서 어떻게 보이나

AI 분석 답변에 이런 내용이 나옴:

```
망원동 저녁(17~21시) 유동인구는 21,300명으로
하루 중 가장 높습니다. 이 시간대 매출이 낮다면
메뉴 구성이나 객단가를 점검해보세요.
```

## Step 4 — 공휴일 데이터

### 뭘 했나

2021~2025년 공휴일 106개를 `holidays.json`으로 저장, AI 분석 시 자동 주입

### 어떻게 좋나

"이번 달에 어린이날이 있어서 매출이 올랐다" 같은 분석이 가능해짐

### 프론트에서 어떻게 보이나

Claude 프롬프트에 자동으로 들어가서 답변에 반영됨:

```
5월은 어린이날(5일) 공휴일이 포함되어 있어
가족 단위 고객이 늘어 음료보다 디저트 매출
비중이 높아지는 경향이 있습니다.
```

## Step 5 — 날씨 데이터 (1,929건)

### 뭘 했나

기상청 ASOS API로 2021~현재까지 서울 일별 날씨를 수집해 `weather_data` 테이블에 저장

- 평균기온, 강수량, 최대풍속, 평균습도

### 어떻게 좋나

"비 오는 날 내 카페 매출이 얼마나 차이 나는지" 실제 데이터로 계산 가능

### 프론트에서 어떻게 보이나

AI 분석 결과에 `날씨 반영` 배지가 뜨고 답변에 이런 내용이 나옴:

```
이번달 강수일이 8일이었는데, 비 온 날 평균 매출
89,000원 vs 맑은 날 115,000원으로 26,000원 차이가
납니다. 우천 시 테이크아웃 할인 이벤트를 고려해보세요.
```

## Step 6 — 소상공인 전략 가이드 RAG (144청크)

### 뭘 했나

소상공인시장진흥공단 PDF 4개를 파싱해서 경영 전략 문서를 RAG에 저장

### 어떻게 좋나

통계 수치만 있던 것에서 "그래서 어떻게 해야 하는지" 실행 전략까지 근거 있게 제시 가능

### 프론트에서 어떻게 보이나

AI 답변의 추천 액션이 더 구체적으로 바뀜:

```
소상공인진흥공단 가이드에 따르면, 비수기 매출 회복을
위한 핵심 전략은 객단가 향상입니다.
1. 세트 메뉴 구성으로 평균 객단가 15% 상향
2. SNS 충성 고객 대상 멤버십 쿠폰 발행
```

## Step 7 — 상권 평균 벤치마킹

### 뭘 했나

`GET /insights/benchmark` API 추가 — 내 매출을 선택한 상권 카페 평균과 비교

- 32개 마포구 상권 드롭다운 선택
- AI 분석과 독립적으로 동작 (매출 데이터 없어도 상권 평균 조회 가능)

### 어떻게 좋나

"나만 매출이 낮은 건지, 상권 전체가 낮은 건지" 객관적으로 확인 가능

### 프론트에서 어떻게 보이나

인사이트 페이지에 항상 표시되는 벤치마킹 카드:

```

│ 상권 평균 벤치마킹                       │
```

## 프론트 테스트 방법

### 사전 준비

```bash
# 1. 백엔드 서버 실행 (프로젝트 루트)
uvicorn backend.api.main:app --reload --port 8000

# 2. 프론트엔드 실행 (frontend/ 디렉토리)
cd frontend && npm run dev
```

브라우저에서 `http://localhost:3000` 접속 → 로그인 후 진행

---

### Step 1·2·3·6 — RAG 데이터 연결 확인 (AI 분석)

**경로**: 대시보드 → AI 인사이트 (`/dashboard/insights`)

1. 연도·월 선택 (매출 데이터가 있는 달 선택)
2. **[AI 분석 시작]** 버튼 클릭
3. 확인 포인트:
   - 답변에 "홍대입구 상권", "유동인구", "카페 평균 월 매출" 등 수치가 나오면 Step 1·3 RAG 연결 성공
   - 답변에 "HH/HL/LH/LL 등급" 언급이 나오면 Step 2 RAG 연결 성공
   - 답변에 "소상공인진흥공단", "객단가", "세트 메뉴" 등 전략 언급이 나오면 Step 6 RAG 연결 성공

> 매출 데이터가 없는 달을 선택하면 "데이터 없음" 안내가 나옴 — 정상 동작

---

### Step 4 — 공휴일 반영 확인

**경로**: 동일하게 AI 인사이트 페이지

- 공휴일이 있는 달(1월·3월·5월·6월·8월·9월·10월) 선택 후 AI 분석
- 답변에 "어린이날", "추석", "설날" 등 공휴일 언급이 있으면 성공
- Claude 프롬프트에 자동 주입되므로 별도 UI 요소 없음

---

### Step 5 — 날씨 데이터 반영 확인

**경로**: AI 인사이트 페이지

- AI 분석 결과 헤더에 **`날씨 반영`** 배지가 표시되면 날씨 데이터 연결 성공
- 답변에 "비 온 날", "강수일", "맑은 날 평균 매출" 등이 언급되면 성공
- 배지가 안 보이면 → 해당 달의 날씨 데이터가 DB에 없는 것 (정상)

---

### Step 7 — 상권 평균 벤치마킹 확인

**경로**: AI 인사이트 페이지 (AI 분석과 별개로 항상 표시)

1. 페이지 로드 시 **상권 평균 벤치마킹** 카드가 자동으로 나타남
2. 드롭다운에서 상권 선택 (예: 홍대입구역(홍대))
3. **[비교하기]** 버튼 클릭
4. 확인 포인트:
   - 내 카페 매출 vs 상권 평균 가로 막대 비교 차트 표시
   - "평균의 X%" 수치와 "상권 평균 대비 +/-금액" 표시
   - 매출 데이터가 없어도 상권 평균만 조회 가능

> 벤치마킹은 AI 분석 버튼과 독립적으로 동작 — 로그인만 되어 있으면 언제든 사용 가능

---

### 빠른 API 테스트 (백엔드 직접 호출)

```bash
# 상권 목록 확인
curl http://localhost:8000/insights/areas

# 벤치마킹 테스트 (user_id는 Supabase에서 확인)
curl "http://localhost:8000/insights/benchmark?user_id=<YOUR_USER_ID>&area=홍대입구역(홍대)&year=2024&month=10"

# AI 분석 테스트
curl -X POST http://localhost:8000/insights/analyze \
  -H "Content-Type: application/json" \
  -d '{"user_id": "<YOUR_USER_ID>", "year": 2024, "month": 10}'
```
