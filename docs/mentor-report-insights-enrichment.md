## 각 데이터가 AI 답변에 미치는 차이

**상권 통계 + 유동인구 연결 전/후**
```
전  "주말에 집중적으로 프로모션을 고려해보세요."
후  "홍대입구 상권 카페는 금·토 매출이 전체의 40%,
     토요일 유동인구 72,000명으로 평일 대비 1.7배입니다.
     토요일 오후 3~5시 집중 프로모션이 효과적입니다."
```

**날씨 + 공휴일 연결 전/후**
```
전  "5월은 성수기입니다. 매출 유지에 신경 쓰세요."
후  "5월에 강수일 9일 + 어린이날 연휴가 겹쳤습니다.
     비 온 날 평균 매출 89,000원 vs 맑은 날 115,000원.
     연휴 당일 디저트 세트 구성으로 객단가를 올려보세요."
```

**전략 가이드 연결 전/후**
```
전  "매출 회복을 위한 다양한 전략을 시도해보세요."
후  "소상공인진흥공단 가이드에 따르면 비수기 핵심 전략은
     객단가 향상입니다. 세트 메뉴로 평균 15% 상향,
     SNS 충성고객 멤버십 쿠폰 발행을 권장합니다."
```
