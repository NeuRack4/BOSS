# 사업자 등록할 때 필요한 서류들

--

## 1. 사업자등록 신청서

```
[ 사업자등록 신청서 ]
(소득세법 제168조 / 부가가치세법 제8조 관련)

■ 인적사항
  - 상호(법인명):
  - 성명(대표자):
  - 주민등록번호:
  - 전화번호:
  - 사업장 주소: 서울시 ___구 ___동 ___번지

■ 사업 내용
  - 업태: 음식업
  - 종목: 카페 / 제과점 / 분식  (해당 항목에 ○)
  - 개업 연월일: 20__년 __월 __일
  - 사업장 면적: ___㎡

■ 사업자 유형
  □ 일반과세자
  □ 간이과세자  (연 매출 1억 400만원 미만 시 선택 가능)

■ 공동사업자 여부
  □ 없음
  □ 있음 → 공동사업자 명세 별첨

■ 제출 서류 체크리스트
  □ 신분증 사본
  □ 임대차계약서 사본
  □ 식품영업 신고증 사본

신청일: 20__년 __월 __일
신청인: ___________  (서명 또는 인)

세무서장 귀중
```

> 온라인 신청: 홈택스(hometax.go.kr) → 사업자등록 신청/정정
> 방문 신청: 관할 세무서 민원실

## 2. 신분증 사본

별도 서식 없음 — 아래 조건 충족 여부를 확인 후 복사/스캔하여 제출합니다.

```
[ 신분증 사본 제출 체크리스트 ]

  □ 주민등록증 또는 운전면허증 (여권도 가능)
  □ 앞면 전체가 선명하게 복사 또는 스캔
  □ 주민등록번호 뒷자리 마스킹 권장
     예) 800101 - 1******
  □ 흑백 복사 가능 (컬러 불필요)
  □ 훼손·글자 가림 없이 전체 내용 식별 가능할 것
```

## 3. 임대차계약서 사본

법제처 표준 상가건물 임대차계약서 기반 템플릿입니다.

```
[ 상가건물 임대차 계약서 ]
(상가건물임대차보호법 적용 여부: 환산보증금 서울 9억원 이하 시 적용)

임대인 (갑)
  - 성명:                   주민번호:
  - 주소:

임차인 (을)
  - 성명:                   주민번호:
  - 주소:

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 임대 목적물
  - 소재지: 서울시 ___구 ___동 ___번지
  - 건물명:
  - 층 / 호수:
  - 면적: ___㎡  (약 ___평)
  - 용도: 음식점 영업

■ 계약 조건
  - 보증금:  금 ___________원 (₩_________)
  - 월 차임: 금 ___________원 (₩_________)
  - 관리비:  금 ___________원 (₩_________)
  - 임대 기간: 20__.__.__ ~ 20__.__.__

■ 계약금 / 중도금 / 잔금
  - 계약금:  금 _______원  납부일: 20__.__.__
  - 중도금:  금 _______원  납부일: 20__.__.__
  - 잔  금:  금 _______원  납부일: 20__.__.__

■ 특약 사항
  1. 임차인은 음식점(카페 / 제과점 / 분식) 용도로만 사용한다.
  2. 권리금: ___________원  (없을 시 "해당 없음")
  3. 원상복구 범위: ___________________________
  4. 계약 갱신 요구권 행사 여부: □ 행사함  □ 미행사
  5. 기타:

■ 확정일자
  □ 계약 후 관할 세무서 또는 법원에서 확정일자 신청 (임차인 보호를 위해 필수 권장)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

계약 체결일: 20__년 __월 __일

임대인 (갑): ___________  (서명 또는 인)
임차인 (을): ___________  (서명 또는 인)
공인중개사:  ___________  (등록번호:          )
```

## 4. 식품영업 허가증 / 신고증

### 4-1. 업종 구분 (제출 전 반드시 확인)

| 업종 | 해당 영업 | 주류 판매 |
|------|-----------|-----------|
| 휴게음식점 | 카페, 빙수, 간단한 분식 | 불가 |
| 일반음식점 | 식사 제공, 주점 겸업 | 가능 |
| 제과점 | 빵·과자류 제조 및 판매 | 불가 |

### 4-2. 식품영업 신고서 (구청 위생과 제출)

```
[ 식품영업 신고서 ]
(식품위생법 시행규칙 제42조 제1항 관련)

■ 영업자 정보
  - 영업자 성명:
  - 생년월일:
  - 주소:
  - 연락처:

■ 영업장 정보
  - 영업소 명칭 (상호):
  - 영업소 소재지: 서울시 ___구 ___동 ___
  - 영업장 면적: ___㎡
  - 영업의 종류:
    □ 휴게음식점
    □ 일반음식점
    □ 제과점

■ 첨부 서류
  □ 식품위생교육 수료증
  □ 건강진단결과서 (보건증)  — 영업자 본인 포함 종사자 전원
  □ 영업장 평면도  (시설 배치도)
  □ 수질검사성적서  (지하수 사용 시에만 해당)

신고일: 20__년 __월 __일
신고인: ___________  (서명 또는 인)

○○구청장 귀중
```

### 4-3. 진행 순서

```
① 식품위생교육 수강  (한국식품산업협회 등 지정기관, 6시간)
          ↓
② 보건증 발급  (관할 보건소, 약 3~5일 소요)
          ↓
③ 식품영업 신고  (관할 구청 위생과 방문 또는 정부24 온라인)
          ↓
④ 신고증 수령  (즉시 또는 수일 내 발급)
          ↓
⑤ 사업자등록  (홈택스 또는 세무서, 신고증 사본 첨부)
```
