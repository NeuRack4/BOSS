# 진행상황
- 컨텐츠 마케팅 자동화 시도
- 많은 이탈로 인한 주제 변경

# 새 프로젝트
- 제목: BOSS (Business Operations Support System) — 서울 1인 창업자 Proactive AI 비서
- 타겟: 서울에서 처음 창업하는 F&B 소상공인 (카페, 베이커리, 분식 등) -> 스코프를 조정하였습니다.
- 서비스형태: 기능단위 페이지와 챗봇 조합. 
## 핵심 기능
1. 서류 초안 작성
  - 한글 파일의 경우 불가능하면 제외하고 pdf등 다른 문서를 한글로 변환 시도 해보기
2. 상권 입지 분석(시뮬레이션)
  - 참고자료: https://github.com/666ghj/MiroFish
3. 지원사업 공고 모니터링
4. 세금관련 스케쥴링
5. 규제법(식품 안전법, 소방법 등 가이드)
6. 채용 자동화(알바 채용 시점 추론, 공고 생성)
7. 챗봇.
8. 마케팅
9. 매출관리
- 매출이 떨어질때 오를때의 전략을 각각 
- 카페에서 누가 구매한걸 영수증으로 땡겨오던가 자동으로 우리 프로그램에 매출이 입력되고 전년, 전달 대비 상승, 하락을 볼 수 있어야함. erp.
10. 데이터분석 및 통찰력 제공.
- 저번달 대비 어떤 것 때문에 왜 변했는지 등을 알 수 있어야함.
- 매출에 대한 카페 분석
- llm, rag 등으로 나타내야함

# 질문
## 포르젝트 범위 대한 문의
- 기능 범위와 도메인 분야의 범위
- 기능 범위는 기획나온것들의 우선순위를 정해서 리스트업하고 우선순위 높은순으로 프로젝트끝날때까지 순차적으로 하나씩 격파하는식으로. 
- 도메인 분야는 차라리 카페등 하나의 분야로 정하고 오히려 기능을 최대한 많이 구현해보는게 좋을듯.

# 서비스 시작시
- 사업 내용 입력받기
  - 챗봇으로 입력받거나
  - 입력 폼을 직접 받거나.
- 기획시 사용자가 처음 서비스에 접속해서 시작할 그림을 그리면서 진행하면 기획이 잘 그려짐.
- 처음 시작할땐 도메인이나 데이터 범위를 최대한 작게 잡아서 빠르게 검증해보는걸 추천드립니다.

## 비서 업무의 시작과 끝을 어떻게?
- 해당 사용자가 사업을 중지할때까지.
- 서비스 사용히스토리와 대화내역에서 추출한 메모리 기반으로 넥스트 해야할것을 에이전트 스스로 파악해서 끝없이 비서로서 도움을 줄수 있도록 컨셉을 잡도록 해야할듯. 
- 서비스에 제공할 기능들이나 워크플로우를 고정적으로 정하면 진짜 똑똑한 사람같은 비서느낌이 덜함. 최대한 데이터와 도구들 직접 액션할수 잇는 판을 잘깔아주고 어느정도 자유도를 높여주는게 진자 사람같은 에이전트를 개발하게 됨
